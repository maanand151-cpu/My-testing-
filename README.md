# 🎓 Question Solver AI App

AI-powered educational app with 3 FREE APIs:
- ⚡ **Fast Mode**: Groq API (Instant answers)
- 🧠 **Deep Mode**: Google Gemini (Detailed analysis, 2/day limit)
- 🎨 **Advanced Mode**: Gemini + Internet Image Search (2/day limit)

## 🚀 Setup
1. `cd backend && npm install`
2. `cp .env.example .env` → Add your FREE API keys
3. `cd ../mobile-app && npm install`
4. Backend: `npm run dev`
5. Frontend: `npm start`

## 🔑 FREE APIs Required
- Groq, Gemini, Hugging Face, Bing/Unsplash, MongoDB Atlas
All free tiers available.
